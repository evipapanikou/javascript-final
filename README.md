# javascript-final

This project is a user registration form that validates user input fields in real time using **vanilla JavaScript**. The form is styled with **Bootstrap 5** and includes dynamic error messages for invalid inputs.

The code also includes a password visibility toggle using an eye icon, along with DOM manipulation and event handling.

**Technologies**
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (vanilla)

About the Project

This project was developed as part of my JavaScript training, with a focus on applying fundamental JavaScript concepts to a practical web form.
